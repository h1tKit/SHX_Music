🛠️ 技术栈

- 开发框架：Qt6.9.1（QML + C++ 混合编程）
- 核心模块：
  * QtMultimedia：音频播放控制
  * QtQuick.Controls：UI 组件
  * taglib：解析音频元数据（歌名、歌手、专辑等）
- 运行平台：Linux（已在 Manjaro 测试，兼容 Ubuntu 等主流发行版）

----
📋 使用说明

- 导入音乐：
  * 点击主界面 "添加音乐" 按钮，选择 "添加文件" 或 "添加文件夹"
  * 支持批量导入.mp3、.wav、.flac、.ogg 格式文件
- 播放控制：
  * 双击歌曲列表中的歌曲开始播放
  * 工具栏可切换播放 / 暂停、上 / 下一首、调节音量
  * 右侧按钮可切换播放顺序（顺序 / 随机 / 单曲循环）
- 歌词显示：
  * 点击 "正在播放" 按钮切换到歌词界面
  * 点击工具栏 "桌面歌词" 按钮显示 / 隐藏桌面歌词
  * 桌面歌词支持拖动（解锁状态）和锁定（固定位置）
- 收藏歌曲：
  * 在歌曲列表点击 "♥️" 按钮添加到 "我的喜欢"
  * 可在 "我的喜欢" 界面管理收藏的歌曲
